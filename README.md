# Megamania Remake

Jogo de tiro espacial em pixel art inspirado no clássico Megamania.

## Como rodar

Abra `index.html` em um navegador moderno.

## Controles

- Desktop: `←` e `→` para mover, `Espaço` para atirar
- Mobile: botões na tela

## Regras

- A barra de energia cai continuamente
- Destruir toda a onda recarrega a energia e avança de nível
- Cada nível alterna o visual dos inimigos
